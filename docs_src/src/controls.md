# Controls

Every key the mod binds, by group, and the game's own keys it leaves in place. Keys are keyboard only. F1 shows the subset that does something where you are; that is usually what you want.

## Global

| Key | Function |
| --- | --- |
| F1 | Keys here: the keys that do something on this screen, each runnable with Enter |
| Ctrl+Shift+M | Mod menu |

## Navigation

| Key | Function |
| --- | --- |
| Arrows | Move focus; Left/Right change a slider or chooser |
| Tab / Shift+Tab | Next / previous control group |
| Enter | Activate, as a click |
| Backspace | Details, as a right-click: character sheets, item text |
| Escape | Cancel a search; else close the top panel; else the game's Escape |
| Home / End | First / last item of the list |
| Alt+Up / Alt+Down | Previous / next section |
| Letters | Type-ahead search in the focused group, outside a fight |

The game's Escape closes its popups, or opens its menu when none is up.

## Buffers

| Key | Function |
| --- | --- |
| Ctrl+Right / Ctrl+Left | Next / previous buffer |
| Ctrl+Up / Ctrl+Down | Next / previous line |

## Glances

On a control that concerns a hero or a monster of your run, in a fight or between fights:

| Key | Function |
| --- | --- |
| Ctrl+1 | Its hp and shields |
| Ctrl+2 | Who it targets and who targets it |
| Ctrl+3 | Its statuses |

In a fight:

| Key | Function |
| --- | --- |
| Ctrl+I | What hits the party this turn |
| Ctrl+T | Turn, rerolls and mana |

## Die Sides

Outside a fight, on a control that concerns a hero, monster or class (the inventory, a character sheet, the almanac, the Choose-Party list), the digits read its die's sides one at a time, in the order the character sheet lists them.

## The Game's Keys

### In a Fight

| Key | Function |
| --- | --- |
| R | Roll dice (while rolling) |
| 1 to 9 | While rolling, lock or unlock hero N's die; while targeting, select hero N, or target N once something is selected |
| Shift+1 to 9 | Target N on the other side |
| Q, W, E, R, T, Y, U, I | Select ability 1 to 8 |
| Z | Undo |
| Space | Done rolling, or end turn |

### Between Fights

| Key | Function |
| --- | --- |
| 1 to 9 | Start reward N at a level's end; choose option N in a choice |
| I | Inventory |
| R | Randomize equipment, in the inventory |
| I or Escape | Leave the inventory |
| Space | OK, on a message |
