# Changelog

## V0.1.4

- Options no longer read their first dropdown options when opening.
- Converted previous choosers to proper dropdowns.
- Added hero buffers to party blessings.

## V0.1.3

- Fixed unit effects being announced for an already dead unit.
- Fixed Escape from a details panel losing focus; it now returns to the item that opened it.
- The Choose-Party class list is grouped by colour and says each class's hp.
- Number keys read a class's die sides in the Choose-Party list, its party slots, and the almanac.
- Hero and monster buffers now work for classes and monsters in the almanac and the Choose-Party list, including a class's spell and its description.
- Details panels (Backspace on a class, almanac pages, in-run hero dialogs) now read like the character sheet, with die faces named by position.
- Almanac hero and monster entries say their hp.
- The copy button on hero and monster panels can be reached when the game's copy option is on.
- Fixed the first-fight reroll question being read as a choice confirmation, where yes would reroll the party.
- The first-fight reroll button says when it is unavailable or will count as a loss.
- Skipping a level-two level-up now gives the game's "not recommended" warning.
- Choices of paths in custom and TextMod content can now be read and picked.
- Fixed leaderboards closing as soon as they opened; they also say their qualifying score.
- Event dialogs (anvil, challenge, cursed chest, class reroll, position swap, rewards) say item tiers, monster hp, and what you lose or gain.
- Level-end rewards no longer read as "ChoicePhase" or "chain".
- Almanac marks (not encountered, seen this run, banned this run) come from the game's records, and a hero's panel there reads its chosen record and run marks.
- Graph tab: the add-side list names every side and marks plotted ones, and the value table follows hero or monster mode.
- The Options tab lists options in the game's order.
- Fixed deleting a stored Paste scenario whose name matches a card button.

## V0.1.2

- More shortcut keys: ctrl+i in combat reads incoming damage, numbers outside combat read hero die faces.
- Added machine-assisted translations.

## V0.1.1

- Fixed not being able to see hero color.
- Fixed party layout buffers lacking blessing keyword descriptions.
- Dice now display their position instead of raw number.
- Fixed inconsistent ability readouts in combat wherein the abilities would not announce their keywords.
- Items and blessings that teach a spell now describe it.
- Hero buffers and character sheets now list the hero's own spell, along with other traits the game shows beside the die.

## V0.1.0

- Initial release
