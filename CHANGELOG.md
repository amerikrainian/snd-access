# Changelog

Release notes, newest first. Each `## VX.Y.Z` section becomes the GitHub
release body (and what the installer reads back as "What's new").

## V0.1.0

Initial release. Full screen-reader support for Slice & Dice: every screen —
title, combat, rewards, inventory, almanac, options, leaderboards — is
navigable by keyboard and spoken through Prism (NVDA, SAPI, and other backends).
The game's own hotkeys keep working alongside the virtual cursor.
